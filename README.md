# Avaliação JP IA

Estrutura centralizada:

```text
aula-exemplo-jp-ia/
├── frontend/
├── backend/
├── documentos/
├── prompts/
├── docs/
└── demais arquivos existentes
```

## Frontend

```powershell
cd frontend
npm install
npm run dev
npm test
npm run build
```

## Backend

```powershell
cd backend
npm install
npm run dev
```

Para entender a função de cada parte, os endpoints e como iniciar frontend e backend separadamente, consulte [docs/como-funciona.md](./docs/como-funciona.md).
